# v2.9.2 — Simplified reverse preview

`npm run preview` now puts each reverse-import result directly in `bpmn-to-json/` as a pair: `<name>.bpmn` is the unchanged source XML and `<name>.json` contains the imported model and warnings. The warning summaries `coverage.md` and `coverage.json` moved to the timestamped preview root.

Model-generated XML and hand-written XML fixtures are still both checked. A colliding hand-written fixture name receives an `xml-` prefix. PNG files remain under `json-to-bpmn/` for the forward-generated diagrams.
