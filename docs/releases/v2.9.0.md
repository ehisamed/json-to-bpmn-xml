# v2.9.0 — Safe BPMN XML import

Adds `importBpmn(xml)` and `BpmnImporter` for BPMN XML → supported `ProcessModel` JSON. The result includes `model`, structured `warnings`, and the unchanged `sourceXml`.

Unsupported elements and flows connected to them are omitted from the JSON projection. If no supported process remains, or the partial JSON cannot be regenerated by `convert`, `model` is `null`. For parseable BPMN XML, the original XML is returned so BPMNDI positions, engine extensions, and other information outside the JSON model are not lost. Malformed XML rejects with a parse error. This is not a lossless round trip.

The new import tests re-export all 39 model fixtures and cover an XML fixture with an unsupported ad-hoc subprocess and dependent boundary/sequence flows. See [the import guide](../bpmn-import.md) for usage and limitations.

`npm run preview` now processes both model and XML fixtures, separating results under `json-to-bpmn/` and `bpmn-to-json/` in each timestamped preview folder.
