# v2.9.1 — Reverse-import preview coverage

`npm run preview` now imports all generated XML from `fixtures/models/` back to JSON, as well as the XML files in `fixtures/xml/`. In each timestamped preview folder, `json-to-bpmn/` contains the forward XML/PNG results. `bpmn-to-json/from-models/` and `bpmn-to-json/from-xml/` contain source XML, imported JSON with warnings, and regenerated XML/PNG where possible.

`bpmn-to-json/coverage.md` and `coverage.json` group actual importer warnings into missing coverage, dependent dropped flows, and informational layout changes. Activity data input/output associations now produce an explicit warning instead of being silently omitted. The report is a guide for follow-up work, not a claim of exhaustive BPMN semantic equivalence.
