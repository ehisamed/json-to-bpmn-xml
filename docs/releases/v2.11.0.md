# v2.11.0 — Ad-hoc subprocess support

The JSON model, direct converter, and reverse importer now support BPMN `AdHocSubProcess`.

Use `subProcess.subProcessType: "adHoc"` with optional `ordering`, `cancelRemainingInstances`, and `completionCondition`. Ad-hoc inner activities may have no sequence flows because their runtime order is not fixed. Outer sequence flows and boundary events are preserved during reverse import.

The fixture and preview coverage now include a parallel incident-review checklist. The former hand-written ad-hoc XML fixture also imports without structural warnings. The importer remains conservative for extensions and metadata outside the supported JSON fields.
