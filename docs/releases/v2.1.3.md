# v2.1.3

Add a structured GitHub bug report form for json-to-bpmn-xml.

- Distinguish conversion and validation errors, BPMN XML problems, diagram layout and routing, imports / types, local tooling and documentation issues.
- Require the affected version, actual and expected behavior, and a minimal reproduction.
- Include optional runtime, BPMN viewer, error / XML output, screenshot and regression details.
- Accept reports in English or Russian and link the input model references.
- Add a bug reporting link to the README.

Validation: package build passed; issue form YAML and field definitions checked; the example reproduction converts and parses without warnings.

The issue form becomes available in GitHub's issue chooser after it is merged into the repository's default branch.
